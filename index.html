Find instrument key

        

          
          
        

        

        

        
Downloads Upstox's public NSE instrument file once per session (~60MB) and searches it locally — unreliable on mobile browsers (large file can freeze the tab). For known/common stocks, it's faster to just ask Claude for the ISIN and build the key yourself as NSE_EQ|<ISIN>.

        
Available F&O expiries for a symbol: NSE publishes these; ask Claude if you're unsure of the exact date, or check the Upstox app's option chain screen for that stock.

      

      

        
Upstox connection

        

          
          
        

        

          
          
          
        

        

        
You said you don't have Upstox API access yet — register at upstox.com/developer, create an app, complete OAuth login to get an access token (a normal login token lasts ~1 trading day; an Analytics Token lasts 1 year), and find the instrument key for the stock in Upstox's published instrument master (NSE.json). This panel is fully wired once you paste a token.

FII / DII activity

        
NSE's own data is blocked by a login/cookie wall no proxy can complete. This instead reads Upstox's public FII/DII page — no login needed there, but it works by parsing their webpage, so it can break if Upstox redesigns that page. Cash-market segment only.

13 · Backtesting & Validation

        
Walk-forward historical evaluation runs automatically for the selected stock when enough CSV history is available. The live panel reports sample size and available performance metrics across 1-, 5- and 20-session horizons.

        
Historical results can be noisy and may not reflect executable fills. Cost assumptions are illustrative; taxes, liquidity, slippage and market impact may differ.

        
      

    

    

      
14 · News & Sentiment

        
Recent headline lookup and keyword-based sentiment are shown for the selected stock in the Intelligence Dashboard. News availability and relevance can vary by symbol.

        
Sentiment is a simple text signal, not a verified assessment of company fundamentals. Check original reporting before acting.
