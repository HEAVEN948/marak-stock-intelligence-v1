Find instrument key

Downloads Upstox's public NSE instrument file once per session (~60MB) and searches it locally — unreliable on mobile browsers (large file can freeze the tab). For known/common stocks, it's faster to just ask Claude for the ISIN and build the key yourself as NSE_EQ|<ISIN>.
Available F&O expiries for a symbol: NSE publishes these; ask Claude if you're unsure of the exact date, or check the Upstox app's option chain screen for that stock.

Upstox connection

You said you don't have Upstox API access yet — register at upstox.com/developer, create an app, complete OAuth login to get an access token (valid ~1 trading day), and find the instrument key for the stock in Upstox's published instrument master (NSE.json). This panel is fully wired once you paste a token.
